# RunAnalysis
RunAnalysis on the data from Coursera specialisation "Getting and Cleaning Data" by Johns Hopkins University

## Project Purpose
The purpose of this project is to demonstrate the ability to collect, work with, and clean a data set. The goal is to prepare a tidy data set that can be used for subsequent analysis using data collected from the accelerometers of the Samsung Galaxy S smartphone.

## Repository Files

* **`README.md`**: This file, providing an overview of the repository and explaining how the scripts work and are connected.
* **`CodeBook.md`**: A code book that describes the variables, the data, and the transformations performed to clean up the data.
* **`run_analysis.R`**: The R script used to execute the 5-step data cleaning pipeline.
* **`tidy_dataset.txt`**: The final data output generated by the script, containing the summarized tidy data.

## How the Script Works

To run the analysis, execute the `run_analysis.R` script in RStudio. The script automatically performs the following steps:

1. **Merge Datasets**: Combine the training and testing sets (measurements, activity labels, and subject identifiers) into one unified data frame.
2. **Extract Mean and Standard Deviation**: Filter the 561 original features down to only the variables that represent a mean or standard deviation measurement.
3. **Apply Descriptive Activity Names**: Replace numeric activity IDs (1 to 6) with descriptive words (e.g., `WALKING`, `SITTING`).
4. **Label the Dataset Appropriately**: Clean up variable names by removing special characters and expanding short terms (e.g., replacing `t` with `time`, `Acc` with `Accelerometer`, and `Gyro` with `Gyroscope`).
5. **Generate Tidy Output**: Group the data by subject and activity, calculate the average of each variable for that specific group, and write the output to `tidy_dataset.txt`.
